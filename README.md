# Açaí Prime

App de açaiteria feito com React Native e Expo. 

## Como rodar

Precisa de Node (versão LTS) e do app Expo Go no celular, ou de um emulador Android/iOS.

```bash
git clone https://github.com/hss-hss/acai-prime.git
cd acai-prime
npm install
npm start
```

Com o servidor rodando, escaneie o QR code com o Expo Go ou aperte `a` (Android), `i` (iOS) ou `w` (navegador).

Também dá para abrir direto:

```bash
npm run android
npm run ios
npm run web
```

## Stack

- Expo
- React Native
- TypeScript
- @expo/vector-icons

```
assets/       imagens e ícones
```
